# PuntoSushi POS
Es un sistema automatizado de control de stock, ventas y administrador de pedidos.

_**Este sistema se encarga únicamente de mostrar valores de diferentes productos con fines de asistir al cálculo de la renrabilidad de diferentes productos, el sistema no emite boletas ni está relacionado con ningúna entidad de procesamiento de pagos bancarios**_

## Iniciando el sistema
Cuando ingrese a la página web, se encontrará con una pantalla de inicio de sesión, donde debe colocar sus credenciales, si tiene problemas con esto contacte al administrador o al equipo de soporte [EDFM](Soporte.com) 

Una vez dentro lo primero que se verá son los pedidos activos, esto está estructurado así para que sea más sencillo montar el sistema en dispositivos de navegación compleja (ex. Televisores)
